养基发财 · 前端风格方案对比

四种方向都渲染同一套真实业务内容（总资产 / 当日收益 / 累计收益 / 持仓列表 / 状态标记 / 买入弹窗 / 底部导航）， 便于横向对比配色、字体、形状与信息密度。选定后我把该套语言落地到全部页面与弹窗。
可直接访问：/ui-style-preview/a-terminal.html b-editorial.html c-horology.html d-industrial.html

A 深空数据终端 新标签打开

近黑底 + 青色强调 + 等宽数字，网格刻线、2px 方角、高信息密度。专业数据终端气质，与现有金色玻璃风差异最大。

B 纸本编辑风 新标签打开

象牙纸底 + 墨黑文字 + 朱红单点强调，衬线体大数字、极细发丝线、大量留白。冷静克制，出版物质感。

C 墨金制表风 新标签打开

墨玉深底 + 克制金色点睛 + 表盘刻度 + 金属三层光源。克制的奢华，延续现风格但做减法精修。

D 暖陶工业风 新标签打开

暖炭灰底 + 赤陶/琥珀强调，2px 粗描边、大圆角模块、颗粒质感。厚重质朴的工业仪表盘感。

第二批 · 新增方向

E 瑞士信号白 新标签打开

冷白底 + 纯黑结构线 + 极小面积信号红，零圆角、零阴影、8px 网格底纹、全大写微字距标签。国际主义网格的瑞士排版。

F 沙丘米白 新标签打开

暖沙米白底 + 深橄榄主交互 + 陶土色点缀，衬线大数字、20px 大圆角、柔和投影与暖沙光晕。温暖有机的柔和质感。

G 暮色紫晶 新标签打开

深紫底 + 紫罗兰渐变强调 + 呼吸光晕，24px 大圆角、发光胶囊状态、多层径向紫光晕。夜间发光的沉浸柔光。

H 荧光海报 新标签打开

纯黑底 + 3px 白粗描边 + 荧光黄绿强调 + 印刷硬投影，超粗 Archivo 大数字、网点底纹、位移硬切换。粗野海报的高对比冲击。

终选方案 · 深色（C 墨金全套 · 只换字体，3 个变体）

V1 DM Sans（App 现有） 新标签打开

C 的配色/圆角/光晕/刻线 全部不动，只把 Cormorant Garamond 换成 App 现有 DM Sans + JetBrains Mono。最中性、最正常。

V2 Archivo 新标签打开

同上，数字/展示换成 Archivo。字面更宽更硬，数据终端感最强。硬朗理性。

V3 单一家族（思源黑体） 新标签打开

全站只用思源黑体一个家族（数字/正文/代码同源），彻底消除混排带来的“有大有小”观感。最统一、零杂音。

REF C 原版（Cormorant 衬线） 新标签打开

未经字体替换的原始 C，作对照。识别度最高，但衬线数字不属“正常字体”。

终选方案 · 浅色（F 沙丘）

LIGHT 浅色 · 沙丘 新标签打开

取自 F 沙丘米白（#F2ECE1 + 橄榄 #3E4A33 + 陶土 #C4703F），保留 Fraunces 衬线数字。落地到浅色主题。
